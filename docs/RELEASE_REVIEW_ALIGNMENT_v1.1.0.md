# 发布评审对齐记录

## 采纳

- v1.1.0 冻结，只修 P0/P1，不新增功能。
- 发布门禁、边界审计、已知问题、发布说明、模块交互矩阵进入当前工作。
- v1.1.x 只做备份/恢复、回收站、搜索筛选、自定义分类、空状态等低风险小补。
- v1.2 再做预算/周期提醒、习惯打卡、行前清单、收据附件、手动多币种、本地 PIN。

## 按现有产品修正

报告中的“无网络请求”不能原样成立：现有产品包含可选 AI、Open-Meteo 天气和同一 WiFi 局域网会话。
因此边界改为：**无账号、无云端后台、无遥测、无支付；网络只允许用户主动触发的 AI/天气和局域网会话，禁止后台静默联网、第三方统计 SDK 和外网远程控制。**

## 暂不进入 v1.1.0

- 本地备份/恢复
- 回收站
- 全局搜索
- 自定义分类/标签
- 本地 PIN
- 提醒/周期账单
- 收据附件
- CSV/PDF 导出

这些进入 `docs/MODULE_INTERACTION_MATRIX.md` 的 v1.1.x / v1.2 backlog。

## 仍未完成

- Android 正式分发所需的独立 release keystore。
- Windows 安装包商业代码签名。
- 本地备份/恢复与回收站等数据安全小补。
