# 行囊 Knapsack v1.4.0 发布说明

v1.4.0 新增「目标」模块（Mod 07）：把一句话想法收成可执行的四层结构，并能把 Claude Desktop 等外部 AI 的讨论结果整包导入。

## 主要变化

- 新增「目标」模块，导航位置在「每日」和「账房」之间。
- 想法池：记录原始想法，可标记已澄清、搁置，或晋级成目标。
- 目标树四层：目标 → 里程碑 → 任务 → 周期；进度按任务完成比例实时计算。
- 里程碑必须写可验证的验收口径，任务要求动词开头、可独立执行。
- 两轮 AI 拆解：第一轮只出针对原文的澄清问题，第二轮产出目标包；结果先在预览页确认，确认后才写库。
- `goal-pack.v1` 导入：支持粘贴 JSON 或代码块，按 `externalId` 增量更新，重复包会二次确认，包内未出现的旧条目不会删除，本地状态不会被覆盖。
- 新增 `skills/knapsack-goal` 技能：在 Claude Code / Claude Desktop 里把讨论规范化成 goal-pack。
- 目标的 6 张表纳入本地备份与恢复，恢复后其余模块数据按备份原样回写。

## 兼容与边界

- 数据库名与既有表结构不变，不迁移、不清除既有数据。
- 备份格式仍为 `knapsack-backup.v1`，新增的是 `mod_goals_*` 六张表。
- AI 拆解只在用户点击时发起请求，需要先在「设置」里配置 OpenAI 兼容接口；未配置时按钮给出明确提示，不会后台请求。
- 导入不提供身份认证，仅按 `externalId` 匹配内容。

## 验证
