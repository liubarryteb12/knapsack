# 行囊 Knapsack v1.3.2 已知问题

- Android release 仍使用 debug keystore 签名，仅适合内部试用。正式分发前必须替换独立 release keystore。
- Windows 安装包和 portable 未做商业代码签名，SmartScreen 可能提示未知发布者。
- 分享链接直接携带压缩后的正文，长提示词会形成长链接。部分聊天软件可能折叠或截断链接，发送时应完整复制。
- 提示词分享不包含缩略图、历史、收藏和调用次数。接收方导入后生成本机新 ID。
- 旧分享码和旧网页链接继续兼容，但旧数据仍受导入时当前 Schema 校验约束。
- 团队和旅行局域网二维码继续使用现有扫码链路，本轮未改其设备兼容性。
