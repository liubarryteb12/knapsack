# 行囊 Knapsack v1.2.0 发布说明

v1.2.0 是微内核架构和提示词卡带版本，同时完成每日计划、账房、旅行与团队子系统的边界收敛。

## 主要变化

- 开放 ModManifest 自动发现、路由、导航、启停、插槽与能力总线。
- 新增提示词库：工作、生图、生视频三态 Schema，变量 Runner，词块字典，缩略图、二维码分享和全局速存。
- 每日计划加入 50 步撤销重做、时间块拖拽、跨零点分钟轴和幂等跨日顺延。
- 账房加入整数分最大余额法、消费成分双轴、旅行净实付、预算水位和含旅行/仅日常视图。
- 旅行页面、组件、store、团队域、团队 DB action 与 LAN 引擎完成物理收敛，旧路径仅保留兼容 facade。
- 新增统一备份恢复、SHA-256 校验、Blob 编解码与敏感凭证脱敏。

## 数据兼容

- 保留 `knapsack` 数据库名和 v1-v4 旧表。
- 新代码读写 `mod_*` 沙箱表，升级事务内完成旧表镜像。
- 提示词媒体使用独立 `prompts_media` 表。
