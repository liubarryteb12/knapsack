# 行囊 Knapsack v1.3.2 发布说明

v1.3.2 将提示词分享从二维码改为链接，并提高长提示词的容量，同时把编辑器标签改成可选的预设分类。

## 主要变化

- 提示词分享改为复制 `knapsack-prompt://share?d=...` 链接，不再生成提示词二维码。
- 分享弹窗支持粘贴链接导入，并继续兼容旧 `knapsack-prompt/1`、`knapsack-prompt/2` 分享码和旧网页链接。
- 长正文使用 gzip 压缩后写入链接，复制、聊天软件传递和粘贴导入都不依赖扫码。
- 提示词正文上限从 20,000 字提高到 50,000 字，工作、生图和生视频的正文字段统一使用新上限。
- 编辑器字段改为 `适用场景`、`分类`、`风格 / 技巧`三组预设下拉。
- 三组预设均支持多选和筛选，每组末尾提供 `其他（手填）`，选择后才显示手填框。
- 分类预设包含提示词、工作规范、流程 SOP、模板、检查清单、分析框架、角色设定、写作方法、运营方案和操作手册。
- Windows 注册 `knapsack-prompt://` 协议，支持冷启动导入和运行中单实例链接转发。
- Android 注册相同协议，支持冷启动待处理链接和运行中 `onNewIntent` 导入。
- 团队和旅行局域网二维码继续保留，不受提示词分享改版影响。

## 兼容与边界

- 保留 `knapsack` 数据库名和既有表结构，不迁移或清除现有提示词数据。
- 提示词链接包含正文和标签，不包含本机 ID、收藏、调用次数、历史和参考图。
- 分享链接是内容传递方式，不提供身份认证或服务端短链接。

## 验证

- 38 个自动化测试文件全部通过。
- Vue 类型检查和 Vite 生产构建通过。
- 模块边界审计和 Rust 离线编译通过。
- Android release 与 debug 构建通过，Windows NSIS 构建通过。
