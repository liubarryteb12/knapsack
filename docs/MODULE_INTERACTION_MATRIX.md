# 模块交互矩阵与数据引用关系

## 原则

1. 松耦合：模块可独立关闭，不阻塞主流程。
2. 单向引用：只引用 ID，不复制“真相数据”。
3. 可关闭：跨模块交互可在设置中关闭。
4. 降级安全：被引用数据删除后，引用方显示降级状态，不崩溃。
5. 不复制真相：账目、任务、行程各保留一份权威数据。

## 数据引用规则

- 旅行花费导入账房：账房保存 `sourceTripId + sourceExpenseId`，不反向修改旅行。
- 未来旅行 → 每日任务：任务保存来源 `tripId + itemId`，旅行删除后任务显示“来源已删除”。
- 未来账房 → 每日摘要：每日只读聚合摘要，不复制账目明细。
- 未来任务 → 账房：任务只保存 `financeEntryId`，账目删除后显示“关联账目已删除”。
