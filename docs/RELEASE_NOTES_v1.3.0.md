# 行囊 Knapsack v1.3.0 发布说明

v1.3.0 将团队协作从旅行模块中独立出来，形成可跨旅行、提示词和每日计划复用的通用团队分享卡带。

## 主要变化

- 新增独立 `/team-hub` 团队分享工作台，旧 `/teams` 与团队详情路由继续兼容。
- 新增 `ShareablePackage` 标准包，覆盖作者、权限、版本、payload 与 SHA-256 完整性摘要。
- 装箱器支持只读分发与协同上报，可一次选择多个业务模块的数据包。
- 分片二维码支持 gzip、CRC32、乱序重组与多帧轮播。
- 旅行、提示词、每日计划均支持导出、审核、受控合入和版本 Diff。
- 导入后再次导出会复用 `packageId` 并递增 `revision`，形成连续修订链。
- 同版本异内容、旧版本回退、跨包链覆盖和缺失词块引用默认拒绝。
- 只读包会创建新的旅行、提示词或每日计划日期副本，不覆盖本机主键。
- 审核页会隐藏已采纳或驳回版本以下的旧待审包，并阻止并发合入多个包。
- 团队包批量装箱使用单事务，任一记录失败时整批不落库。

## 体验与兼容

- 390px 下团队工作台、装箱器、二维码和 Diff 页面无横向溢出，弹窗内容可滚动。
- 团队群组子路由保持主导航选中态。
- 保留 `knapsack` 数据库名、旧业务表与团队旧路由，供升级和回滚使用。
- 新增 `mod_team_groups`、`mod_team_packages` 等 `mod_*` 沙箱表。
