# 行囊 Knapsack v1.1.2 发布说明

## 版本定位

v1.1.2 是 v1.1.1 之后的性能、内存与边界收口版本，不新增业务模块。

## 变更

- 旅行列表改为摘要投影：完整 `days/expenses/notes` 只在详情页按需读取。
- 旅行列表按 24 张卡片有界分页，支持名称/城市搜索，避免 1700 条数据一次性挂载 DOM。
- 1700 条合成基准：完整聚合根 4,272,401 B → 摘要 362,121 B，常驻数据约 -92%。
- 账房导入去重改为 `sourceKey` 索引查询，不再全量读取账目表。
- 团队列表投影改为 Dexie 流式读取，避免完整 `TeamState` 大数组常驻。
- AI 探活、模型列表、天气查询全部改为用户显式点击，禁止页面挂载时后台联网。
- 账房月份切换增加请求序号，旧查询晚返回不会覆盖当前月份。
- 无批次费用恢复上报、确认和入账链路。

## 验证

- 15 个 TypeScript 回归脚本全部通过。
- `npm run build` 通过。
- `npm run audit:boundary` 9/9 通过。
- 账房 5000 条窗口基准、旅行 1700 条摘要基准均有可复跑脚本。
- Android Debug/Release、Windows setup/portable 构建产物与 Web 资产同步。

## 边界

- 数据默认存本机 IndexedDB。
- 无账号、无云同步、无遥测、无支付/转账/银行卡接口。
- 可选 AI、天气、局域网会话只在用户明确操作后联网。
