# 行囊 Knapsack v1.3.0 用户使用教程

本教程只介绍日常使用，包括安装、导航、五个功能模块、团队分享、备份恢复和常见问题。

## 1. 安装与首次打开

### Windows

1. 安装 `Knapsack-1.3.0-x64-setup.exe`，或直接运行免安装版 `Knapsack-1.3.0-portable.exe`。
2. 如果系统提示未知发布者，请先确认安装文件来源可信。
3. 首次启动无需注册或登录，应用默认打开“我的旅行”。

### Android

1. 安装 `Knapsack-1.3.0-release.apk`，系统要求 Android 7.0 及以上。
2. 首次安装时，系统可能要求允许当前文件管理器或浏览器安装应用。
3. 打开应用后无需注册，数据默认保存在当前设备。

### 首次打开

如果关闭了全部模块，应用会进入“设置”。重新打开需要的模块即可。

## 2. 导航与模块开关

桌面端使用左侧导航，手机端使用底部导航：

| 导航名称 | 页面标题 | 主要用途 |
| --- | --- | --- |
| 旅行 | 我的旅行 | 行程、预算、行李、备忘和旅行互传 |
| 每日 | 每日规划 | 当日任务、时间块、随手备忘和每日复盘 |
| 账房 | 日常账房 | 本地花费、月度预算和消费结构 |
| 提示词 | 提示词库 | 工作、生图、生视频提示词 |
| 团队 | 团队分享 | 群组、标准包、二维码收发和审核合入 |
| 设置 | 设置 | 主题、模块、备份恢复和 AI 接口 |

### 打开或关闭模块

1. 进入“设置”。
2. 找到“模块”卡片。
3. 打开或关闭“旅行、日常规划、日常账房、提示词库、团队分享”。
4. 关闭模块只会隐藏入口，不会删除数据。

“模块开关（按旅行）”还可以控制单个旅行中的“预算”和“备忘”页面。

## 3. 旅行

### 新建旅行

1. 在“我的旅行”点击“新建旅行”。
2. 填写名称、开始日期、结束日期、目的地类型、城市和总预算。
3. 保存后打开旅行详情。

旅行详情通常包含“行程、预算、行李、备忘”四个页面。部分页面可在设置中关闭。

### 行程

1. 在“行程”中点击“添加条目”。
2. 选择交通、住宿、餐饮、游玩或其他类型。
3. 填写日期、时间、标题和备注。
4. 条目可以勾选完成、拖拽排序、跨天移动，也可以撤销和重做。

### 预算与花费

1. 在“预算”中填写总预算和分类预算。
2. 先添加参与成员，再记录花费。
3. 每笔花费可选择“均分、按份、自定义金额”。
4. “结算建议”会计算成员之间的应付关系，不会发起真实转账。

### 行李与备忘

- “行李”支持城市、海边、山野和通用模板，也可以自行增删分组与条目。
- “备忘”停止输入约 1 秒后自动保存。

### 导入和导出 `.trip`

- “导出”会生成一个 `.trip` 文件，可作为单次旅行的备份或分享文件。
- “导入 .trip”会先检查文件内容，再让你选择覆盖原有旅行或另存为新旅行。
- `.trip` 只包含一份旅行，不等同于全应用备份。

### AI 行程草稿

1. 先在“设置 → AI 接口配置”填写 AI 服务地址、密钥和模型名。
2. 回到“我的旅行”，点击“AI 行程草稿”。
3. 填写目的地、日期和偏好，生成并预览草稿。
4. 确认后只会保存为新旅行，不会覆盖现有旅行。

AI 功能需要网络和可用的 AI 服务。密钥只保存在当前设备，生成请求会发送到你填写的服务。

### 天气

打开旅行详情后，点击“查看目的地天气”才会查询外部天气服务 Open-Meteo。应用不会在后台自动查询天气。

城市名称需要能够匹配，旅行日期需要在可用预报窗口内。离线或查询失败时，天气区域会隐藏或保留重试入口。

### 旅行互传

旅行互传用于同一 WiFi 下的两台设备同步一份旅行。

主机端：

1. 在 Windows 桌面版打开某个旅行。
2. 点击“局域网会话”。
3. 选择正确的连接地址并显示二维码。
4. 保持面板打开。

接入端：

1. 打开同一旅行并点击“局域网会话”。
2. 扫描主机二维码，或粘贴会话码。
3. 选择“从主机拉取”或“把我的版本推给主机”。

同步是整份覆盖，不做逐项自动合并。关闭主机会话面板后，接入会立即失效。会话码不要截图外发。

## 4. 每日规划

“每日规划”用于按日期组织任务、时间块、备忘和复盘。

1. 选择日期，或点击“今天”回到当天。
2. 在今日计划中输入任务并点击“添加”。
3. 可设置开始时间和结束时间，形成时间块。
4. 勾选完成、编辑或拖拽调整任务。
5. 使用“一键顺延”把昨日未完成任务带到今天。
6. 在“随手备忘录”记录临时信息，停止输入后自动保存。
7. 在“每日复盘”填写三个复盘问题。

## 5. 日常账房

1. 进入“日常账房”并选择月份。
2. 设置本月预算水位。
3. 在“快速记一笔”填写日期、金额、类别、消费成分和备注。
4. 查看月度合计、分类结构和近 7 日趋势。
5. 点击“导入旅行花费”可以选择旅行账本中的花费复制到账房。

旅行花费导入只读取旅行花费，不修改旅行账本。同一笔花费重复导入时会自动跳过。

账房只做记录和统计，不接入支付、转账、银行卡或其他金融接口。

## 6. 提示词库

“提示词库”用于保存可复用的工作、生图和生视频提示词。它本身不会调用任何模型。

### 新建提示词

1. 点击“新建提示词”。
2. 选择“工作、生图、生视频”类型。
3. 填写标题、正向提示词、负向提示词、标签和缩略图。
4. 工作类提示词支持变量：
   - `{{变量}}`
   - `{{变量:默认值}}`
   - `{{变量:A|B|C}}`
5. 生图和生视频提示词可以引用“词块字典”中的常用词块。

### 运行提示词

1. 在提示词卡片上点击“运行”。
2. 选择输出方言。
3. 填写变量值。
4. 点击“复制并计次”，组装后的文本会复制到剪贴板。

### 词块与分享

- “词块字典”可以新建、导入和导出常用词块。
- 单条提示词可以生成分享码或二维码。
- 二维码过密时，改用“复制分享码”。
- 提示词分享只包含正文和标签，不包含收藏状态、调用次数、历史和缩略图。

### 全局速存

应用右侧的全局速存入口可以快速保存当前看到的提示词片段。保存后到“提示词库”继续编辑分类和变量。

## 7. 团队分享

“团队分享”由群组和标准包两部分组成。

- 群组负责名册、分工、审批和团队快照。
- 标准包负责把旅行、提示词或每日计划装箱，通过二维码或文件面对面传输。

### 管理群组

1. 在“团队分享”点击“管理群组”。
2. 组织者点击“创建团队”，填写团队名称和组织者名称。
3. 成员点击“扫码加入”，扫描组织者会话码或粘贴会话码。
4. 成员提交申请后，组织者在“分工设置”中审批。

组织者页面包含“分工设置、汇总与确认、会话与发布”。成员页面包含“连接组织者、我的任务、我的上报”。

团队汇总会话需要一台手机作为现场主机。主机需要保持团队页面在前台，不要锁屏或切到后台。

### 装箱分享

1. 在“团队分享”点击“装箱分享”。
2. 选择一个群组，也可以不关联群组，直接面向附近设备分享。
3. 选择分享权限：
   - “协同上报”：接收方可以作为协作成员提交内容。
   - “只读分发”：接收方获得独立副本。
4. 勾选要分享的旅行、提示词或每日计划。
5. 点击“确认装箱”。

账房当前不作为标准包来源。账房数据请使用全应用备份。

### 二维码收发

发送方：

1. 打开“扫码收发”。
2. 选择“发送共享包”。
3. 选择发送箱中的包，开启二维码。
4. 内容较大时会出现多帧轮播，保持屏幕常亮。

接收方：

1. 打开“扫码收发”。
2. 选择“接收共享包”。
3. 打开相机连续扫描对方轮播二维码。
4. 可以分多次扫描，收齐后自动进入待审核。

如果相机不可用、权限未开或二维码不易扫描，可使用对应的分享码或团队资料文件。

### 审核与合入

1. 接收完成后打开待审页面。
2. 核对来源模块、版本、作者和内容变化。
3. 点击“采纳并合入”或“驳回”。
4. 合入前应用会检查版本、冲突、缺失内容和权限。

应用会自动检查共享包是否完整。作者身份和最终合入仍需要你在本机审核确认。

## 8. 备份与恢复

### 导出全应用备份

1. 进入“设置”。
2. 找到“本地备份”。
3. 点击“导出备份”。
4. 保存生成的备份文件。

备份包含各模块的业务数据和模块开关。备份文件不含团队配对信息，恢复后需要重新配对。

### 恢复备份

1. 在“本地备份”点击“选择备份”。
2. 选择备份文件。
3. 核对文件名和覆盖提示。
4. 点击“确认恢复”。

恢复会整体替换当前全部应用数据。应用会先检查文件是否完整，格式不符时拒绝恢复。

### 其他备份方式

- `.trip` 只备份一份旅行。
- 提示词分享码只包含一条提示词。
- 团队标准包只包含本次装箱的业务数据。
- 以上三种方式都不能替代全应用备份。

版本变化记录保存在当前设备。卸载应用或系统“清除数据”会删除本机内容，也不会自动生成云端副本。

## 9. 常见问题

### 数据看起来不见了

先检查是否关闭了对应模块。关闭模块只隐藏入口，不会删除数据。

如果切换过日期、月份或旅行，确认当前筛选条件是否正确。不要直接清除应用数据。

### 两台设备连不上

- 确认两台设备在同一 WiFi。
- 关闭访客网络、网络隔离或代理工具。
- 主机保持应用页面在前台。
- 如果设备有多个网络地址，可以切换显示出来的连接地址。
- 旅行互传和团队会话只适合面对面使用，不经过云端中转。

### 二维码扫不全

- 保持两台设备屏幕常亮。
- 让对方二维码轮播完整循环。
- 调整距离和角度。
- 内容较大时改用分享码或资料文件。

### 备份恢复后团队不可用

团队配对信息不会进入备份文件。恢复后重新扫码让组织者审批即可。

### Windows 提示未知发布者

先确认安装文件来源可信，再按系统提示继续。

## 10. 隐私与网络

- 核心数据默认保存在当前设备。
- 无账号、不上传数据到云端、不收集使用数据、不提供云同步。
- AI 请求只会发送到你配置的 AI 服务。
- 天气请求只会在你点击“查看目的地天气”后发送到外部天气服务 Open-Meteo。
- 旅行互传和团队二维码只连接同一现场的附近设备。
- 应用不提供支付、转账、银行卡或其他金融接口。

## 11. 当前版本提示

- 当前安装包适合内部试用，系统可能提示未知发布者。
- 大体积共享内容需要使用多帧二维码连续扫描。
- 提示词共享包不包含缩略图。
- 每日计划只读包会创建新的日期副本，避免覆盖本机同名日期。

遇到本教程未覆盖的问题，请先导出全应用备份，再记录应用版本、设备型号和出现问题前的操作步骤。
