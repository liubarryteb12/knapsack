# 行囊 Knapsack v1.1.1 发布说明

## 版本定位

v1.1.1 是 v1.1.0 候选版的性能与精简迭代，不新增业务功能。

## 变更

- 旅行详情低频组件延迟加载：局域网会话、预算、行李、备忘、AI 草稿只在需要时加载。
- 旅行详情路由图从 1,123,773 B 降至 929,715 B（约 -17.27%）。
- 账房改为月份 + 近 7 日窗口查询；5000 条基准下加载数据量约减少 92%。
- 二维码扫描器异步化消融无收益，已回退，保持现有动态导入策略。
- `teamActions.ts` 只完成职责审计和拆分边界，不在候选版大搬迁。

## 验证

- 14 个测试脚本通过。
- `npm run build` 通过。
- `npm run audit:boundary` 8/8 通过。
- Android release 安装验证与 Windows portable 启动验证。

## 边界

- 数据默认存本机 IndexedDB。
- 无账号、无云同步、无遥测、无支付/转账/银行卡接口。
- 可选 AI/天气/局域网会话是显式用户触发路径。
